**Tideglass** — a tide-and-moon catching game. Mara the tidekeeper wades the moonlit shallows, catching falling tideglass orbs in her net to fill the Moon Jar before the moon sets. Dodge spiky urchins and snapping crabs, gather shells for bonus points, and chain combos as the tide quickens and the moon climbs. A complete, original 2D canvas arcade game: title, play, pause, win and game-over screens, score, lives, levels, combos, keyboard and mouse controls, synthesised WebAudio sound, and procedural art only — no external assets, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` from any static file server. Node 22.18+ and a desktop browser such as Chrome are all it needs; there is no build step and no dependency to install. `node main.ts` (with `MAKEFUN_OUTPUT_DIR` set outside the grader) writes the entry's `game/`, `screenshots/` and `dossier.json` to the output directory.
